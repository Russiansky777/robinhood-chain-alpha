# robinhood-chain-alpha

Исследовательский проект: есть ли алгоритмический эдж в копитрейдинге
персистентно прибыльных кошельков на **Robinhood Chain** (Ethereum L2 на
Arbitrum Orbit, chain id `4663`, mainnet с 1 июля 2026).

**Спринт 1 — kill-тест гипотезы о персистентности.** Гипотеза: кошельки,
прибыльные в июле 2026, остаются статистически значимо прибыльнее
контрольной группы в августе 2026. Если тест это не подтверждает —
гипотеза копитрейдинга «купи топ по PnL за прошлый месяц» убита на старте,
и спринт 2 не имеет смысла запускать в текущей форме.

## Статус

⚠️ **Данные ещё не выгружены и тест ещё не прогнан.** Причина и план —
в [`docs/DATA_ACCESS.md`](docs/DATA_ACCESS.md). Коротко: у текущей
исполняющей среды нет ни ключей API (Dune/Alchemy), ни сетевого доступа к
`api.dune.com` / `*.alchemy.com` (egress-политика окружения блокирует эти
хосты, подтверждено `403` на CONNECT). Весь пайплайн написан и готов к
запуску — не хватает секретов и/или запуска через GitHub Actions
(у раннеров GitHub полный доступ в интернет).

## Структура

```
sql/        Dune SQL — по одному файлу на шаг пайплайна (сырые свопы →
            фильтр снайперов → агрегация по кошелькам → когорты)
analysis/   Python: оркестрация Dune API, статистика, сборка когорт,
            построение отчёта
docs/       Методология, решения по каждому гейту, план результатов
.github/    workflow, который гоняет пайплайн на секретах репозитория
```

## Как запустить (когда есть ключи)

```bash
cp .env.example .env   # заполнить DUNE_API_KEY (и опционально ALCHEMY_API_KEY)
pip install -r analysis/requirements.txt
python analysis/run_pipeline.py
```

Либо: положить `DUNE_API_KEY` / `ALCHEMY_API_KEY` в GitHub → Settings →
Secrets and variables → Actions, и запустить workflow
`.github/workflows/run_pipeline.yml` вручную (`workflow_dispatch`).

Результаты пишутся в `analysis/output/` (git-ignored, кроме финального
отчёта, который пайплайн копирует в `docs/RESULTS.md`).
