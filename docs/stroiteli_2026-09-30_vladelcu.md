## 1. БЛОКЕР: приёмка Code-1 падает и отчёта не пишет

`deploy/checks/priemka_stroitelya.py` (ветка `claude/nifty-sagan-r0polg`, коммит
`4c3d6dd`). Правка, которая должна была лечить обрыв на шаге «байт в байт»,
недоделана:

* строки 441--444: ранний `return` стоит только если `tpl is None` **И** у типа нет
  своего строителя;
* строки 445--451: ветка `if tpl is None` пишет `из_["байт_в_байт_why_not"]` и **НЕ
  выходит**;
* строка ~462: безусловно `а0, а1 = tpl.get("arg0"), tpl.get("arg1")`.

При `tpl is None` это `AttributeError: 'NoneType' object has no attribute 'get'`.
Охватывающего `try/except` в функции `разбор` нет, вызов в `main()` тоже не обёрнут,
а отчёт пишется только после цикла -- значит прогон падает целиком и
`data/priemka_stroitelya.json` не перезаписывается.

Бьёт по обоим типам без записи в `SPECS`: **Whirlpool** (его приёмка так и не дала
ни одного из трёх чисел -- 72 из 72 «шаблон не восстановился») и **следующий прогон
CLMM** (в прогоне 22:42:46Z таких строк было 40 из 174, то есть упадёт на первой).

Лечится одной из двух правок: продолжать ветку через `tpl = tpl or {}`, либо
завернуть шаг «байт в байт» в `if tpl is not None`. **До этого заказывать приёмку
Whirlpool и AMM v4 бессмысленно -- отчёта не будет.**

```python

    "675kPX9MHTjS2zt1qfr1NYHuzeLXfQM9H24wFSUt1Mp8": "c2_ammv4_stroitel",
```

`2fcdba9`.
