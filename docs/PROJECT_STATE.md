## Правила работы с Dune (оплачены ~1400 кредитами ошибок)

1. Сырые данные не покидают Dune: наружу через API — только агрегаты (тысячи строк максимум). Чтения результатов биллятся по объёму: чтение 1.2M строк стоило 164 кредита.
2. Санитарная проверка ДО исполнения: оценка >40 кредитов ИЛИ множественное сканирование тяжёлых CTE (UNION ALL по сырым свопам) = жёсткий стоп.
3. Отклонение факта от оценки >2x = немедленный стоп сессии.
4. Смоук-тест на одном дне данных до любого полнопериодного прогона.
5. Постоянный кэш data/sprint*_cache/ с коммитом сразу после каждой оплаченной операции; эфемерному кэшу Actions не доверять (гибнет при ненулевом exit).
6. Бюджетный гард: data/credits_spent.json, проверка до КАЖДОЙ платной операции (execute И чтения), лимит на спринт в конфиге, превышение = exit. Лимит поднимается только явным решением владельца, максимум дважды.
7. Состояние цикла (обновлено 2026-09-01, владелец -- внешний якорь, см. docs/COST_POSTMORTEM.md ревизия 5): потрачено 2138.84 из 2500 (реальный пул, не 2450), сброс 14.09.2026. Резерв 20 неснижаемый. Мультиаккаунты запрещены.
8. Пороги в деньгах, не в голых кредитах (владелец, 2026-09-01): кредит ≈ несколько центов на текущем плане. Операции дешевле ~$1 (порядка 30–40 кредитов) не требуют ни остановки, ни доклада штабу -- просто выполняются. Автоматические стопы (кап пространства спринта, >2x при факте ≥25 кредитов, санитарная проверка >40 на один запрос) остаются в силе как жёсткие технические ограничители -- этот пункт про то, что НЕ обязательно докладывать о штатных дешёвых шагах, не про отмену самих стопов.

## Протокол микро-лайва ($100)

Проверяет механику, НЕ прибыльность (позиции $5–15 не дают статистики PnL). Логировать обязательно: полная стоимость раунд-трипа (газ входа+выхода, комиссия пула, налог токена); слиппедж «цена при сигнале → цена исполнения»; задержки (сигнал→отправка, отправка→блок); каждый ханипот и реверт; отказы фильтра (какие токены забраковал и почему); несостоявшиеся сигналы с причиной; ежедневная сверка балансов бот↔чейн. С первого дня: лимит дневного убытка, кап позиции, стоп по серии фейлов транзакций, стоп по расхождению факт/модель.
