# X: верхние 300 по обороту — соцсигналы закрыты окончательно

Последний заход по социальным сигналам, 17.10. Выборка — верхние по обороту, отбор без
подглядывания в исход; счёт по стандарту; контроль случайным входом.

**Коротко: первый пост раньше пика — у 3.3 % токенов (10 из 300; 4.5 % от 221 реально
просмотренных) при пороге 20 %, и бэктест по посту минусовой на всех трёх выходах и хуже
контроля. Оба условия закрытия выполнены. Apify больше не нужен. Всего потрачено
0.1494 USD.**

## Выборка: 300 верхних по обороту за 21–23.09

По 100 на сутки, верхние по SOL первой минуты жизни пула — величина, замеренная в МОМЕНТ
запуска, а не по исходу. Диапазон 431…15 423 SOL, медиана 951. Все 300 оказались из
дошедших до пула — это свойство данных (крупные запуски переезжают), а не отбор.

Файл: `data/podbivka/x_vyborka_top300.json`.

## Сбор в X: что стоило и что получилось

| | значение |
|---|---|
| адресов просмотрено | **221 из 300** (денежные потолки сработали: 90 + 93 + 38) |
| с хотя бы одним постом | **16** — 7.2 % от просмотренных, 5.3 % от всех 300 |
| стоимость захода | **0.1230 USD**, 0.00056 USD на адрес |
| с пилотом и контролями | **0.1494 USD** |

Почему вышло дороже обещанных ≈ 0.08: актор берёт **минимум за вызов** (≈ 0.001 USD)
независимо от числа результатов — это написано в его же служебной записке, которую он
отдаёт, когда ничего не нашёл. Пилотная оценка 0.00026 USD на токен была снята в пакетном
режиме (десять адресов на вызов), а поадресный режим стоит вчетверо дороже. Потолки,
заложенные до запуска (0.04 USD на задание), сработали и остановили проход — поэтому
просмотрено 221, а не 300.

**Окно поиска актор не соблюдает.** Просили «создание … +15 минут», а из 16 найденных
первых постов 11 попали в окно, а 5 нет — два из них на +1020 и +1220 минут. Значит
«первый пост» из этого сбора — это один из трёх НОВЕЙШИХ постов про адрес, а не самый
ранний: доля «раньше пика» от такого сбора — нижняя граница.

## Вердикт

**Соцсигналы закрыты окончательно: первый пост раньше пика у 3.3 % токенов (10 из 300,
4.5 % от 221 просмотренных) против порога 20 %, ни один пост не опередил первую сделку
пула, а бэктест входа по посту минусовой на всех выходах (−0.096…−0.141 SOL на сделку) и
хуже случайного входа на тех же токенах; Apify больше не нужен, всего потрачено
0.1494 USD.**

## Оговорки, которые работают против вывода, а не за него

* окно поиска актор не соблюдает: «первый пост» — один из трёх новейших, значит настоящие
  первые посты могут быть раньше, и доля «раньше пика» — нижняя граница;
* просмотрено 221 из 300 (деньги кончились по потолку) — остаток мог бы добавить
  упоминаний, но при 7.2 % покрытия это не меняет порядок величины;
* удалённые посты и неполнота поиска X смещают выборку к выжившим;
* n у входа по посту — 14 сделок: это слишком мало для стандарта само по себе, и вывод
  держится не на нём, а на доле «раньше пика» и на сравнении с контролем.

Что бы потребовалось для другого ответа: актор с соблюдаемым окном (или X-операторы
`since:`/`until:` в строке запроса), поадресный сбор на всех 300 и, главное, упоминания
хотя бы у пятой части токенов. Первого и второго можно добиться деньгами, третьего — нет:
на верхних по обороту запусках первый пост приходит в среднем через девять минут после
создания и уже после первой сделки.
