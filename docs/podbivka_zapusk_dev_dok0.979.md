## Чем «не Mayhem» читается из архива

Флаг is_mayhem_mode лежит в счёте кривой, но RPC на каждый запуск не поставить. Архивный признак -- дрейф произведения резервов k: у нормальной кривой своп его не двигает, у Mayhem правило цены другое и k уходит. На 127 минтах, у которых флаг прочитан по цепи, дрейф есть у 105 из 109 Mayhem и у 0 из 18 не-Mayhem; четыре промаха -- запуски с 1--3 событиями, где k двигаться не мог. Такие запуски идут строкой «неразличимо» отдельно.
