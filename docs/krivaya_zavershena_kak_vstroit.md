# Завершённая кривая pump.fun: как встроить (для Code-1)

Модуль: `analysis/c3_krivaya_zavershena.py` (самопроверка **14/14**,
`python3 analysis/c3_krivaya_zavershena.py --self-test`). Ни сети, ни ключей,
ни подписи: байты счёта приходят снаружи.

## 1. Дыра, из-за которой он написан

04.10 позиция `D6eyhD2oMTc3HvzHMPwDWC1fHimZbQTED1i8kaS5pump` (вход 0.5 SOL,
кривая pump.fun) провисела непроданной полтора часа. Правило 4 берёт **лучшую**
из двух котировок:

| путь | что сказал | правда |
|---|---|---|
| Jupiter | 11.0 % от входа | да |
| наш пул по резервам | **63.4 % гарантированных (97.5 % ожидаемых)** | **нет** |

Кривая была **завершена**: ликвидность уехала в PumpSwap, а остатки на счетах
кривой всё ещё читались как резервы и давали красивое число. Лучшая из двух —
пул, и полоса пошла бы по цене, которой рынок не даёт.

## 2. Что делает модуль

Один ответ на один вопрос: **можно ли котировать эту кривую по резервам.**

```python
import c3_krivaya_zavershena as KZ
из_ = KZ.mozhno_kotirovat(dannye_schjota_base64)   # из getAccountInfo
if not из_["ok"]:
    # из_["why_not"] -- словами; из_["postojannyj"] -- повтор не поможет
```

* `complete == true` → **«кривая завершена — пути через неё нет, маршрут через
  PumpSwap»**, и отказ помечен как **постоянный**;
* рядом стоит **второй признак, не зависящий от смещения байта**:
  `real_token_reserves == 0`. После миграции на кривой не остаётся токенов.
  Признаки обязаны совпасть; **разошлись — тоже отказ**, по имени. Это защита
  от того, что раскладка счёта однажды сдвинется и отказ молча перестанет
  срабатывать;
* дискриминатор счёта модуль **считает сам** по схеме Anchor
  (`sha256("account:BondingCurve")[:8]` = `17b7f83760d8ac60`), а не держит
  выдуманной константой.

**Формула кривой сверена с цепью:** выход =
`(резерв_противоположный × вход) // (резерв_свой + вход)`. На **пяти живых
покупках** из `data/c2_pool_samples` она даёт ровно то число, что записано в
событии сделки — 5 из 5, без единицы разницы. Запись «резерв − k/(резерв+вход)»
арифметически та же, но округляется в другую сторону и расходилась с цепью на
единицу; на деньгах взята та, что совпала.

## 3. Диф для правила 4 (пять строк)

Место: `analysis/bloom_vtoroe_mnenie.py`, `котировка_пула` — сразу после того,
как собран шаблон и известен счёт пула `сч[0]`, и **до** чтения резервов:

```python
    # КРИВАЯ PUMP.FUN МОГЛА ЗАВЕРШИТЬСЯ: её остатки -- не резервы (04.10, D6eyhD2o).
    if данные_счёта_кривой is not None:                     # одно чтение getAccountInfo(сч[0])
        import c3_krivaya_zavershena as KZ                  # noqa: PLC0415
        к = KZ.mozhno_kotirovat(данные_счёта_кривой)
        if not к["ok"]:
            из_["why_not"] = к["why_not"]; return из_       # метка постоянного отказа уже внутри
```

Чтение: `getAccountInfo(сч[0], encoding="base64")` — **одно**, рядом с теми
двумя, что уже делаются (`остаток_фн(сч[7])`, `остаток_фн(сч[8])`). Для
кривой pump.fun `сч[0]` и есть счёт кривой; для других типов пулов разбор
вернёт «это не счёт кривой» и путь останется прежним — то есть диф безопасен
для всех остальных типов.

Отказ намеренно несёт метку `своим строителем его не котировать`: по ней
`bloom_vtoroe_mnenie.отказ_по_типу_пула` уже считает отказ **постоянным**, и
продавец не будет долбить повторами. Завершённая кривая не оживёт.

## 4. Что нужно от Code-1 для боя (одна команда)

Раскладка счёта взята по публичному IDL pump.fun и проверена изнутри (Anchor-
дискриминатор + два независимых признака + формула, сверенная с живыми
событиями). Чего в репозитории нет — **ни одного сырого счёта кривой**. Чтобы
пришпилить раскладку байт в байт, снять один счёт (только чтение):

```
python3 -c "import json,urllib.request,os;u=os.environ['BLOOM_RPC'];b=json.dumps({'jsonrpc':'2.0','id':1,'method':'getAccountInfo','params':['<СЧЁТ_КРИВОЙ>',{'encoding':'base64'}]}).encode();r=urllib.request.urlopen(urllib.request.Request(u,data=b,headers={'Content-Type':'application/json'}),timeout=10);print(r.read().decode())"
```

Положить ответ в `data/pump_bonding_curve_schjot.json` (две штуки: живая
кривая и завершённая, если найдётся). После этого самопроверка дополнится
проверкой «живой счёт разбирается нашей раскладкой» — и раскладка перестанет
быть «по документации», став «по цепи».
