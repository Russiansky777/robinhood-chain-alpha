## Вердикт

**Закрыто по стоп-правилу: первый пост раньше пика есть у 0 % токенов (постов нет ни у
одного из 50), это ниже порога 20 % — дальше не считаю.** Инструмент при этом проверен и
работает: по слову и по чужому адресу те же прогоны отдают настоящие твиты за те же сутки.

Что именно закрыто, а что нет — чтобы не выдать одно за другое: закрыта проверка на
СЛУЧАЙНОЙ выборке запусков. На ней упоминаний в X по адресу контракта практически не
бывает: из 50 токенов (включая 25 дошедших до пула) ни один не упомянут, и прицельный
контроль на самом крупном из них — 144 SOL за первую минуту — тоже пуст. Гипотеза про
«первое упоминание предсказывает путь цены» на таком материале не проверяема: предсказывать
нечего, сигнала нет физически.

Оговорки, как заложено: удалённые посты и неполнота поиска X смещают выборку к выжившим,
поэтому покрытие и доля «раньше пика» — нижние границы. Пик в производных взят ВНУТРИ окна
(230 слотов у кривых, 1121 у переехавших), настоящий пик может быть позже — это тоже
занижает долю «пост раньше пика», а не завышает.

Если понадобится вернуться к этому вопросу, менять надо выборку, а не инструмент: брать не
случайные запуски, а верхние по обороту или по росту до пика (у таких токенов, как
`$ONBOARD` из контроля, упоминания с адресом есть). Стоимость такого захода известна:
0.00026 USD на токен, то есть 300 токенов — около 0.08 USD. Решение владельца.
