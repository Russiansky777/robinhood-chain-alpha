**Что нужно от Code-1 (сам не делал):**

1. **Пять строк в общем модуле.** `c2_swap_build.min_out_from_reserves` даёт
   f > 1 (до 1.088) у 10 из 25 образцов CPMM, то есть котирует ПОКУПКУ выше кривой
   без комиссии. Причина измерена: в хранилище Raydium CPMM лежат не снятые
   `protocol_fees`/`fund_fees`, резерв меньше остатка счёта. Вычесть их из `x0`/`x1`
   либо, пока не читаются, ограничить f единицей и вернуть это полем. Из-за этого
   круг CPMM — 15 из 25, а не больше.
2. **Три строки в реестре** `analysis/vtoroe_mnenie_reestr.py`: `умеет_продать`
   возвращает True только для Pump AMM, а сборка продажи есть у всех одиннадцати
   типов — поставить `"сборка": "c3_prodavec_sborka"` и вернуть это из `умеет_продать`.
3. **Решение по двум флагам.** Котировка продажи DLMM работает только при
   `BLOOM_DLMM_ODNO_CHTENIE=1` (по умолчанию выключен, это флаг самого
   `c2_dlmm_odno_chtenie`). Без него DLMM продаётся сборкой, но минимум выхода брать
   негде.
4. **Один счёт для DAMM v1** (если тип вообще нужен): `protocol_token_fee` базы —
   одно чтение счёта пула. Без него сборка отказывает по имени.
