## Шаги в торговом пути (после сделки источника)

1. **Пул.** Адрес пула — счёт 0 инструкции `swap` / `swap2` программы DLMM в транзакции источника.
2. **Первое чтение.** `getMultipleAccounts([пул, адрес_расширения(пул)], base64, confirmed)`, затем `lb = разобрать_пул(данные_пула)`. Расширение битовой карты (`разобрать_расширение`) нужно, только если счёт существует.
3. **Какие массивы корзин нужны.** `индексы = нужные_массивы(lb, swap_for_y, 3, ext)`, адреса — `адрес_массива(пул, i)`. Для покупки токена за SOL: `swap_for_y = (lb["token_x_mint"] == WSOL)`, потому что платим X и получаем Y. Если SOL — это Y, то `False`.
4. **Второе чтение — одним запросом.** `getMultipleAccounts([пул] + адреса_массивов)` в одном запросе, чтобы пул и корзины были из одного слота. Затем `массивы = {ba["index"]: ba}` для каждого `ba = разобрать_массив(...)`.
5. **Котировка.** `q = котировка_точный_вход(lb, пул, лампорты_в_пул, swap_for_y, массивы, unix_время, ext)`. Ответ: `q["amount_out"]` — сырые токены на выходе; `q["fee"]`, `q["protocol_fee"]`; `q["корзин"]` — сколько корзин пройдено.
   - Время `unix_время` — время ожидаемой сделки, от него зависит переменная комиссия. Брать текущее время или blockTime слота сделки источника.
   - Если прочитанных массивов не хватило, будет ошибка `ОшибкаDLMM("нет массива корзин N")`. Тогда дочитать массив N и повторить.
6. **Налог Token-2022.** Если у минта есть TransferFee: `налог_вход` / `налог_выход = налог_2022(bps, max)` — у Meteora это `calculate_transfer_fee_excluded_amount`. Налог в модуле по одному bps, без смены по эпохам.
7. **min_out для инструкции** = `q["amount_out"] × (1 − проскальзывание)`.

## Что не входит

- **Проверка активации пула** (`activation_point` для Permission / CustomizablePermissionless) не переносилась. Модуль проверяет только, что пул не выключен (`status`).
- **Комиссия хоста** (host fee) не моделируется — поэтому, возможно, и расхождение −0.001 % в одном свопе: вход брался как прирост хранилища пула. Не проверено.
- **Сделки между нашим чтением и нашей покупкой** меняют состояние. Это то же место в блоке, что и в остальной модели.
