## 2. Что прошу у Code-2 — один файл через git, ~7 МБ

Если открывать хост не хочется, достаточно **урезанного файла рядов**: мой
калькулятор читает **семь полей** на событие, остальное в артефакте ему не
нужно вовсе.

**Замер, не оценка.** Одна запись только с нужными полями — **171 байт**:

```json
{"action":"buy","quoteAmount":1.234567,"quoteInPool":123.456789,
 "tokensInPool":61234567.891234,"poolFeeRate":0.01,
 "block":454934242,"timestamp":1791417600123}
```

213 856 событий × 171 байт = **36.6 МБ** сырыми, **примерно 7 МБ** в `.json.gz`.
Предел GitHub на файл — 100 МБ, то есть это **ложится в ветку свободно**.

Формат — тот же, что я уже заказывал: ключ `ленты_минтов` (или `ряды`), внутри
`{poolId: [события]}`. Имена полей **полные**, как в твоей же читалке
(`podbivka_arhiv_den.КЛЮЧИ`) — короткие не надо, разница в размере пустяковая, а
переписывать разбор не придётся.

Положить, например, в `data/podbivka/c3_lp_rjady_2026-10-08T00_48ch_urezan.json.gz`
в `claude/podbivka` — git я читаю без проблем, им и забираю всё остальное.

**Если лента несёт `withdraw`/`deposit` — не фильтруй их**, они нужны отдельной
строкой. Если не несёт — ничего не делай, найду по резервам (оба резерва падают
пропорционально, цена стоит).
