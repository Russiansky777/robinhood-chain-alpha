## 4. DLMM одним чтением вместо двух

`analysis/c2_dlmm_odno_chtenie.py`, флаг `BLOOM_DLMM_ODNO_CHTENIE`, по умолчанию выключен. Подробно --
`docs/dlmm_odno_chtenie_kak_vstroit.md`. Полосе -- **одна строка**:
`котировщик = c2_dlmm_odno_chtenie.котировщик_для(tx, откат=K.котировка, группа=группа)`.

Адреса массивов корзин берутся из события свопа источника (крайние корзины → индексы массивов → PDA
по окну → пересечение со счетами его инструкций). Совпадение с PDA -- доказательство, чужой счёт не
пройдёт. Всё состояние -- одним `getMultipleAccounts`.

Два отказа на денежном пути, оба по тому же одному чтению: активный массив не среди прочитанных;
перенос поднял «нет массива корзин N». Замер Code-1 (сдвиги −8..+3) и замер Code-2 (40 из 40 через
1--3 слота) друг другу не противоречат -- мерили разное, поэтому проверка стоит на каждом сигнале, а
не в комментарии. На своём отказе зовётся прежний двухчтенийный путь, чтения складываются, сигнал не
теряется.

| рабочего окна индексов хватило (тот же набор при окне 16) | 12 из 12 |
