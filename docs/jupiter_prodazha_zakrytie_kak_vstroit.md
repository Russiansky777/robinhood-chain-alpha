# Продажа через Jupiter с закрытием счёта: как встроить (для Code-1)

Модуль: `analysis/c3_jupiter_prodazha_zakrytie.py` (самопроверка **13/13**).
Ни сети, ни подписи, ни отправки: ответ Jupiter приходит словарём, наружу
уходит порядок инструкций и **размер числом**.

## 1. Зачем

После продажи токен-счёт остаётся пустым, и в нём лежит наша рента ≈ 0.002 SOL.
У кошелька полосы их **404** (`data/bloom_token_accounts.json`: 0.611 SOL
ренты, 401 счёт пуст). Уборка отдельной транзакцией — ещё комиссия и ещё
отправка. Закрытие **в той же транзакции** не стоит ничего, если влезает.

## 2. Как встроить

```python
import c3_jupiter_prodazha_zakrytie as JZ
с = JZ.sobrat(otvet_jupiter,                 # ответ /swap/v1/swap-instructions
              nash_koshelek=кошелёк, token_schjot=наш_ата,
              prodajom_raw=сколько, ostatok_scheta_raw=остаток_счёта)
if с["ok"]:
    # с["instrukcii"] -- порядок; с["zakrytije"] -- готовая инструкция closeAccount
    # с["razmer"], с["zapas"] -- байты
else:
    # с["why_not"] -- почему не влезло, ЧИСЛОМ и до отправки
```

Порядок: `nonce → ComputeBudget×2 → setup → swap → cleanup WSOL (Jupiter) →
**наше закрытие токен-счёта** → чаевые`.

**Два места, где легко потерять деньги, и оба закрыты отказом:**

| случай | что делает модуль |
|---|---|
| продаём **не весь** остаток | закрытия **нет**, причина названа. `closeAccount` на счёте с остатком роняет **всю** транзакцию — то есть и продажу |
| счёт **не участвует в свопе** | закрытия нет: закрыть не тот счёт — отдать чужую ренту и получить отказ |

Оба случая — доказанные красные в самопроверке.

## 3. Размер: где влезает, а где нет

Размер считается аналитически и **сверен с настоящей сериализацией** (solders,
05.10) на четырёх формах, включая форму **с таблицей адресов** — расхождение
**ноль байт**.

| маршрут | байт | влезает |
|---|---|---|
| обычный (20 счетов свопа, 4 setup, **1 таблица**) + nonce + чаевые + закрытие | **574** | да, запас 658 |
| тяжёлый (52 счёта свопа, 8 setup, **без таблиц**) | **2228** | **нет** |
| он же без nonce и чаевых | **2169** | нет |

Главный вес — **статические ключи, 32 байта за адрес**. Пока Jupiter отдаёт
таблицы адресов, закрытие влезает с запасом; маршрут **без таблиц** не влезает
и без закрытия — такие надо отдавать обычным путём, а счёт закрывать уборкой.

## 4. Что нужно от Code-1

Форма ответа взята из живого зонда `data/jup_buy_probe.json` (lite-api, 200:
2 computeBudget, 4 setup, своп на 20 счетов, cleanup, 1 таблица) — но в зонде
записаны **только имена полей**, не значения. Чтобы проверить сборку на
настоящем ответе, снять один ответ целиком (только чтение, ключ не нужен):

```
python3 -c "import json,urllib.request,urllib.parse;q=urllib.parse.urlencode({'inputMint':'<МИНТ>','outputMint':'So11111111111111111111111111111111111111112','amount':'<ОСТАТОК>','slippageBps':'300'});r=urllib.request.urlopen('https://lite-api.jup.ag/swap/v1/quote?'+q,timeout=15).read().decode();b=json.dumps({'userPublicKey':'<КОШЕЛЁК>','quoteResponse':json.loads(r),'wrapAndUnwrapSol':True}).encode();print(urllib.request.urlopen(urllib.request.Request('https://lite-api.jup.ag/swap/v1/swap-instructions',data=b,headers={'Content-Type':'application/json'}),timeout=15).read().decode())" > data/jup_swap_instructions_obrazec.json
```

С этим файлом самопроверка дополнится сборкой на НАСТОЯЩЕМ ответе, и размер
станет считаться по живым счетам, а не по форме.
